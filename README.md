# seanaminov.com

Source for my personal website, built with plain HTML, CSS and JavaScript and hosted on GitHub Pages.

- `index.html` has the content: about, experience, hackathon wins, projects, my Unreal Engine work, skills and contact.
- `style.css` has the dark theme and the layout.
- `script.js` runs the starfield background, the scroll reveals, the course progress bar and the certificate lightbox.
- `assets/` holds my resume, certificates and game design documents.

Live at [seanaminov.com](https://seanaminov.com).
